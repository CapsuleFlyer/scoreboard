## Application and testing work covered by AI assistance

AI assistance was used throughout the project for analysis, implementation support, test development, troubleshooting, and documentation. The work covered the following areas:

- **Application understanding:** Reviewing the existing Flask application, its requirements, business rules, registration workflows, roles, API behaviour, and suspected defects.
- **Test development:** Creating and reviewing unit tests, API tests, registration tests, administrative tests, input validation tests, and recovery tests.
- **Test-data generation:** Developing OpenAPI-based test-data generation for equivalence partitioning and boundary-value analysis.
- **White-box testing:** Analysing control flow, cyclomatic complexity, basis paths, Multiple Condition Coverage, and Modified Condition/Decision Coverage.
- **Mutation testing:** Developing custom mutation operators, analysing surviving mutants, adding tests, and configuring a mutation quality threshold.
- **Coverage analysis:** Producing scoped business-logic coverage reports and whole-application coverage reports.
- **Static analysis:** Setting up and troubleshooting SonarCloud, interpreting issues, comparing baseline and current measurements, and preparing Pareto evidence.
- **CI/CD:** Creating and troubleshooting GitHub Actions quality-gate workflows, status checks, and merge-blocking evidence.
- **Browser and accessibility testing:** Developing and reviewing Playwright tests, keyboard-navigation testing, Lighthouse measurements, and axe accessibility results.
- **Security testing:** Reviewing role and session controls, troubleshooting dependency auditing, and documenting the incomplete OWASP ZAP passive scan.
- **Performance testing:** Developing and troubleshooting k6 test execution for one and five virtual users, including repeated measurement runs.
- **Recovery testing:** Developing and reviewing tests for database outage and recovery behaviour.
- **Quality management:** Preparing test plans, estimates, risk registers, traceability matrices, defect records, root-cause analyses, GQM reports, Pareto analysis, and completion-report material.
